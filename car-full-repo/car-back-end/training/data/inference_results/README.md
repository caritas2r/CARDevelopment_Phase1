# Inference Results

This directory contains results from model inference and testing.

## Files

- **`inference_results_test.jsonl`**: Model inference results on test data
- **`inference_report_test.jsonl`**: Inference report/analysis
- **`test_predictions.jsonl`**: Predictions from model testing
- **`formatted_prediction_results.csv`**: Formatted prediction results in CSV format

## Usage

These files are generated when running inference/testing scripts. They contain:
- Model predictions on test prompts
- Comparison with ground truth annotations
- Performance metrics and analysis

## Related Scripts

See `tools/inference/` directory for scripts that generate these results.
