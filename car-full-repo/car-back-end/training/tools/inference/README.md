# Inference Scripts

This directory contains scripts for running model inference and testing.

## Files

- **`infer_simple_jsonl.py`**: Run inference on JSONL files and generate predictions

## Usage

```bash
python tools/inference/infer_simple_jsonl.py
```

Or modify the script to specify input/output files, or use command-line arguments if supported.

## Output

Inference scripts generate results in `data/inference_results/` directory.
